# Importing the study note into Notion

The tutor writes a Markdown file named like `database-indexes-notes.md`.

## Import

1. In Notion open **Settings**, then **Import**, then **Text & Markdown**.
2. Choose the `.md` file.
3. Open the new page and walk through it.

## What the note uses

Headings, short paragraphs, bullets and numbered lists, bold and inline code, fenced code blocks, plain links, one small comparison table, and a `- [ ]` checklist for the review schedule. Notion documents Markdown import for headings, lists, and code blocks, and says nonstandard extensions may not import cleanly. Depending on your Notion version, the table and the checklist may show up as plain text. The note reads fine either way, because every answer is its own `Answer:` paragraph right below its question.

## Hide the answers

Self-test works best with the answers covered. In Notion, select an answer line and turn it into a toggle, or cover it with your hand. The note does not use toggles itself, because they are not part of the documented Markdown import.

## How to review

Use the checklist at the bottom: next day, about a week, about three weeks. Each time, cover the answers, answer from memory, then check. Start with the shaky spots.
